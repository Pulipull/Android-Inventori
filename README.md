# Inventaris Barang
Android Jetpack Compose Project

## Deskripsi

Aplikasi Android sederhana untuk mengelola data inventaris barang menggunakan Jetpack Compose.
Pengguna dapat menambahkan, melihat, mengubah, dan menghapus data barang melalui antarmuka yang sederhana.

## Fitur

- Menampilkan daftar barang
- Menambah barang
- Mengubah data barang
- Menghapus barang
- Validasi input
- Material 3 UI
